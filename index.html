Raspberry Pi · LED Matrix

spotipi-photos

Adds an Apple Photos slideshow to a Ryan Ward–style spotipi LED-matrix build, with a rebuilt web control panel: modes, live brightness, a working screen-off timer, and a daily schedule.

How it fits together

Photos sync from a named Apple Photos album on your Mac to the Pi. Remove a photo from the album and it disappears from the Pi automatically.

Why it fixes the broken screen-off timer

The original web app turned the panel on and off by systemctl start/stop-ing the display service and restarted it on every brightness change — which made timers and brightness fragile. Here the display daemon is always running and re-reads config/state.json every loop. The web UI only writes that file — no service juggling — so brightness is live and the timer is enforced by the daemon itself.

Web control panel

A Flask UI on port 80, reachable from any browser on your network.

Now on the panel

Live dashboard: a snapshot preview of the matrix, current song/artist or photo, a daemon health dot, and stats — photo count, brightness, last sync, timer left, CPU temp, uptime.

Display modes

On (auto): Spotify art while music plays, photos otherwise. Plus Off, Photos only, and Spotify only.

Live brightness

A 1–100 slider with no restart. This is also the daytime level when the sunrise/sunset dimmer is on.

Photo slideshow

Seconds per photo, plus a Change photo button to skip to the next image immediately.

Screen timer

Turn the panel off after N minutes; the countdown restarts when you save it or tap a Display button.

Daily schedule

A recurring off window that handles overnight spans, e.g. 23:00→07:00.

Sunrise/sunset dimmer

Drops to a lower night brightness between sunset and sunrise, computed from your latitude/longitude — no internet or API key needed.

Two halves

Part ARaspberry Pi

  • Copy spotipi-photos/ to the Pi.
  • Ensure the Spotify token exists (reuse your existing .cache-<username>).
  • sudo bash install_pi.sh installs deps and creates two systemd services: spotipi (display daemon) and spotipi-client (web UI on :80).
  • Set panel details in config/rgb_options.ini (rows/columns, hardware mapping, gpio_slowdown).

Part BMac → Pi

  • Create an Apple Photos album named exactly Spotipi.
  • install_mac.sh + ssh-copy-id for passwordless rsync.
  • sync_album.py rebuilds the album as 64×64 PNGs and rsync -av --delete mirrors it — so deletions propagate.
  • A LaunchAgent runs the sync every 5 minutes.

Automatic updates

mac/auto_update.sh watches for a new spotipi-photos-latest.zip every 6 hours.

When a new version appears it pushes the code to the Pi, restarts the services, health-checks them, and rolls back automatically if they fail to start. It never touches the Pi's live config, photos, or token.

The display daemon falls back to config/default.png whenever there's nothing else to show — e.g. a Spotify token/scope issue. Token refresh is documented in SPOTIFY_TOKEN_RENEWAL.txt.
